# Lichi — website

Website of **Lichi**, a food ingredient scanner for iPhone by Mark Rishko: home page, privacy policy, terms of use and support, in Ukrainian (root) and English (`/en/`).

Published with GitHub Pages: https://lichi.mom/

- Privacy Policy: https://lichi.mom/privacy.html · https://lichi.mom/en/privacy.html
- Terms of Use: https://lichi.mom/terms.html · https://lichi.mom/en/terms.html
- Support: https://lichi.mom/support.html · https://lichi.mom/en/support.html

The pages are generated by `tools/build.py` (Python 3, no dependencies): edit the texts there and run `python3 tools/build.py`. The privacy and terms texts mirror the ones inside the app — change both together.

Contact: lichisupport@gmail.com
